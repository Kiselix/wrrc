# Telegram-бот для рекламных постов

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `BOT_TOKEN` и `ADMIN_ID` в `.env`, затем запустите:

```bash
python bot.py
```

Для публикации подтвержденных постов в отдельный канал укажите его ID в `POST_CHAT_ID` и добавьте бота администратором канала. Фотографии отправляются через Telegram `sendMediaGroup`, поэтому альбом из 2–10 фото отображается встроенной каруселью Telegram с перелистыванием и общей подписью.

Файл `database.db` создается автоматически при первом запуске.

## Возможности

- один бесплатный пост для нового пользователя
- пакеты за Telegram Stars: 1, 5 и 10 публикаций
- подписка за 100 Stars
- проверка обязательной подписки на каналы
- предпросмотр и публикация постов с фото
- базовая админ-панель со статистикой и списком пользователей

Администратор также может использовать команды:

```text
/ban ID
/unban ID
/grant ID ДНИ
/addposts ID КОЛИЧЕСТВО
/channel CHAT_ID | НАЗВАНИЕ | URL
/delchannel CHAT_ID
/broadcast ТЕКСТ
```

Для проверки подписки бот должен быть администратором в обязательных каналах.
